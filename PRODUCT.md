# NeuroQ-Connect

## Register

product

## Users

Seven students building an EEG autism-classification course project, their teaching assistant, and evaluators reviewing the implementation. The team needs a shared foundation that runs locally and supports independent module contributions before a near-term deadline.

## Product Purpose

A research workspace for verifying EEG inputs, running a connectivity-guided quantum-kernel pipeline, inspecting saved subject-wise results, and tracing predictions to model artifacts. Success means a teammate can install the project, understand the interfaces, and reproduce an analysis.

## Brand Personality

Clear, academic, practical. The user confirmed a research-workspace starting screen and a clean academic interface. Use plain English and precise labels, without emojis or decorative copy.

## Anti-references

No marketing landing page, dark neon quantum styling, animated decoration, invented performance numbers, fake patient examples, or unexplained technical buzzwords.

## Design Principles

- Show the real state of data, models, and experiments.
- Make the next action clear when an artifact is missing.
- Keep scientific provenance attached to results.
- Use one shared pipeline for the CLI and interface.
- Make module ownership and handoff contracts easy to find.

## Accessibility & Inclusion

The target is laptop use. Focus future layout, interaction, and testing work on laptop screens. Use labelled native controls, keyboard navigation, readable contrast, and text alongside status colors. No motion is needed for this workspace.
