# NeuroQ-Connect — Visualization and Explainability Module

**NeuroQ-Connect: Connectivity-Guided Quantum Kernels for EEG-Based Autism Classification**

This module provides publication-quality scientific figures and explainability tools for the NeuroQ-Connect research project. It is **one component** of a larger pipeline; it handles visualization and sensitivity analysis only.

> [!IMPORTANT]
> All synthetic figures generated by the example script are for **demonstration only**.
> They are clearly prefixed with `example_` or `synthetic_`.
> Do **not** include them in the final research report.

## Installation

### 1. Clone or navigate to the repository

```bash
cd "neuroq-connect"
```

### 2. Create and activate a virtual environment (recommended)

```bash
python3 -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate.bat    # Windows
```

### 3. Install in editable mode with dev dependencies

```bash
pip install -e ".[dev]"
```

### 4. Optional: Install PennyLane (for quantum circuit visualization)

```bash
pip install -e ".[quantum]"
```

PennyLane is **optional** and only needed when Vivek G's quantum circuit is integrated.

## Module Reference

### `asd_eeg.visualization.eeg`

| Function | Purpose |
|---|---|
| `plot_eeg_traces` | All-channel EEG trace plot |
| `plot_selected_channels` | Subset of channels |
| `plot_eeg_time_window` | Windowed time-segment plot |
| `plot_eeg_power_spectrum` | Welch PSD for each channel |

### `asd_eeg.visualization.connectivity`

| Function | Purpose |
|---|---|
| `plot_connectivity_graph` | 4-node weighted graph |
| `plot_connectivity_matrix` | 4×4 connectivity heatmap |
| `plot_edge_weights_bar` | Bar chart of 6 edge weights |

**Canonical edge order** (always used consistently):
```python
EDGES = [(0,1),(0,2),(0,3),(1,2),(1,3),(2,3)]
```

### `asd_eeg.visualization.quantum`

| Function | Purpose |
|---|---|
| `visualize_circuit` | PennyLane circuit diagram or placeholder |
| `visualize_kernel_circuit_pair` | Side-by-side circuit + kernel heatmap |

### `asd_eeg.visualization.kernels`

| Function | Purpose |
|---|---|
| `plot_kernel_matrix` | Single kernel heatmap |
| `plot_kernel_comparison` | Side-by-side kernel comparison |
| `plot_kernel_distribution` | KDE of kernel values |
| `plot_train_test_kernel` | Training + test kernels side by side |

### `asd_eeg.visualization.results`

| Function | Purpose |
|---|---|
| `plot_model_comparison` | Grouped bar chart of all models |
| `plot_confusion_matrix` | Normalized confusion matrix |
| `plot_roc_curve` | Single-model ROC curve |
| `plot_roc_comparison` | Overlaid multi-model ROC curves |
| `plot_fold_performance` | Per-fold metric line plot |
| `plot_metric_heatmap` | Metric × model heatmap |

### `asd_eeg.explainability.perturbation`

| Function | Purpose |
|---|---|
| `compute_training_references` | Compute per-connection reference values from training data |
| `run_perturbation_analysis` | Sensitivity analysis for one held-out subject |
| `run_batch_perturbation` | Sensitivity analysis for multiple subjects |
| `save_perturbation_results` | Export results to CSV and JSON |
| `plot_perturbation_sensitivity` | Horizontal bar chart of score changes |
| `plot_case_study` | Multi-panel case-study figure |

## Known Limitations

1. **Quantum circuit**: The actual circuit is a dependency on Vivek G's implementation. Until available, only the illustrative placeholder is shown.
2. **Real EEG datasets**: Not included in this repository (too large; ethics-restricted). The example script uses synthetic signals.
3. **PSD computation**: `plot_eeg_power_spectrum` requires `scipy` (not in core dependencies — install separately if needed).
4. **PIL/Pillow**: `visualize_kernel_circuit_pair` uses `PIL` for compositing. Install with `pip install Pillow`.
5. **Model loading**: This module does not handle loading or training models — it only consumes pre-computed scores and matrices.
6. **Perturbation analysis**: Measures model sensitivity only. Results must not be interpreted as causal or clinical evidence.
